# bsg-site
BCA Biological Structures Group website

The BSG website has moved to https://biostructures.org.uk. Every HTML page here is now a stub that sends visitors to the matching page on the new site (`index.html` is a signpost page). Programmes, PDFs and images stay at their old addresses so existing links keep working. A frozen copy of the old pages, hidden from search engines, is kept in `old-site/` for reference.
